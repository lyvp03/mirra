### UC31 – Phối đồ với trợ lý

| Mục | Nội dung |
| --- | --- |
| Tác nhân | Customer; dịch vụ LLM |
| Tiền điều kiện | Đã đăng nhập; còn hạn mức chat |
| Hậu điều kiện | Khách nhận 1–3 set phối đồ hợp lệ theo BR20 |
| Quan hệ | «extend» UC15; được mở rộng bởi UC32 |

Luồng chính:

1. Khách nhắn yêu cầu phối đồ, ví dụ "phối cho mình một set đi làm, dưới 800k", hoặc bấm "Phối đồ với món này" ở trang sản phẩm.
2. Agent gọi `suggest_outfit` với điều kiện rút từ câu hỏi (dịp, ngân sách, màu, món cố định nếu có).
3. Tool lấy ứng viên từ tìm kiếm ngữ nghĩa, lọc theo BR20 (1 món trên + 1 món dưới, còn hàng, đã bật thử đồ), rồi lấy giá và tồn hiện tại từ core-api.
4. Agent trả 1–3 thẻ set: ảnh 2 món, tên, giá từng món và tổng, một câu lý do phối; nút "Thử cả set" và "Thêm cả set vào giỏ".
5. Khách có thể yêu cầu đổi một món trong set; agent lặp lại từ bước 2 với món còn lại cố định.

Luồng thay thế và ngoại lệ:

- 1a. Khách là Guest → vẫn gợi ý set, nhưng nút "Thử cả set" chuyển thành "Đăng ký để thử đồ".
- 1b. Món cố định là đầm liền → agent giải thích đầm liền không phối set, gợi ý thử riêng (UC12).
- 3a. Không đủ món hợp lệ → agent nói rõ điều kiện nào không đáp ứng được và đề xuất nới điều kiện.
- 4a. Khách chọn size cho từng món trên thẻ set rồi bấm "Thêm cả set vào giỏ" → web thêm 2 SKU vào giỏ qua UC06.1. Đây là thao tác trực tiếp của khách trên thẻ, không phải thao tác của trợ lý, nên không qua UC16.
