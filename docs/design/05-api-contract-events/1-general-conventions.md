## 1. Quy ước chung

B5 đặc tả giao tiếp giữa web, core-api, ai-service, worker và hệ thống ngoài theo các interface ở B3 mục 4, dùng bảng dữ liệu ở B4. Quyết định từ khảo sát: docs liệt kê toàn bộ endpoint và đặc tả chi tiết các luồng chính, kèm file OpenAPI 3.1 cho các luồng đó; access token giữ trong bộ nhớ, refresh token trong cookie; chưa thêm tag dịp mặc cho sản phẩm.
