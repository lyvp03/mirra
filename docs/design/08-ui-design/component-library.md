## Thư viện thành phần

Toàn bộ token và component nằm trong [Design System Mirra](https://claude.ai/artifact/9b6hjNcuM5S8zNuxjJwZ1h) — xem token, bản xem trực tiếp của từng component và hướng dẫn dùng. Các màn ở B8 đều lắp từ 34 component này, chia theo nhóm:

| Nhóm | Component |
| --- | --- |
| Điều hướng | Logo, PromoBar, Header, Breadcrumb, SectionHeader, Footer |
| Mua sắm | Button, Badge, Price, ProductCard, SwatchPicker, SizePicker, QuantityStepper, CartItem, OrderSummary |
| Form | TextField, Checkbox, UnderlineInput |
| Danh sách | FilterToolbar, Drawer, SizeGuide, Accordion |
| Phản hồi | StatusChip, Toast, Skeleton |
| Mirra AI | ChatLauncher, ChatPanel, ProductsCard, OutfitCard, ConfirmCard, TryOnPanel |
| Admin | AdminSidebar, DataTable, StatCard |

Quy ước quan trọng: mọi thứ do AI tạo ra (khung chat, ProductsCard, OutfitCard, ConfirmCard, kết quả thử đồ) đều nằm trên nền lilac nhạt hoặc có icon tia sáng màu lilac đậm, và là chỗ bo góc duy nhất — để khách luôn nhận ra khi nào là AI.
