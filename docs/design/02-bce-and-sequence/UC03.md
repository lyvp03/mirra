### UC03 – Reset password

```mermaid
classDiagram
  class PasswordResetForm { <<boundary>> }
  class PasswordResetController { <<control>> }
  class EmailServiceBoundary { <<boundary>> }
  class User { <<entity>> }
  class AuthToken { <<entity>> }
  PasswordResetForm --> PasswordResetController
  PasswordResetController --> User
  PasswordResetController --> AuthToken
  PasswordResetController --> EmailServiceBoundary
```

```mermaid
sequenceDiagram
  actor A as User
  participant F as PasswordResetForm
  participant C as PasswordResetController
  participant U as User
  participant T as AuthToken
  participant E as EmailServiceBoundary
  A->>F: requestReset(email)
  F->>C: requestReset(email)
  C->>U: findByEmail(email)
  opt user exists
    C->>T: create(userId, type=RESET_PASSWORD, expiresIn=30m)
    C->>E: sendResetEmail(email, tokenLink)
  end
  C-->>F: accepted
  F-->>A: showIfEmailExistsMessage()
  A->>F: submitNewPassword(token, newPassword)
  F->>C: resetPassword(token, newPassword)
  C->>T: findValid(token, RESET_PASSWORD)
  alt token valid
    C->>U: updatePassword(userId, passwordHash)
    C->>T: consume(token)
    C->>T: revokeAllSessions(userId)
    C-->>F: passwordChanged
  else expired or used
    C-->>F: error(TOKEN_EXPIRED)
  end
```
