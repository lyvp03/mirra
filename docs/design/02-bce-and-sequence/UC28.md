### UC28 – View assistant traces

```mermaid
classDiagram
  class TraceViewerScreen { <<boundary>> }
  class TraceController { <<control>> }
  class TraceStoreBoundary { <<boundary>> }
  class Conversation { <<entity>> }
  class ChatMessage { <<entity>> }
  class PendingAction { <<entity>> }
  class AICostRecord { <<entity>> }
  TraceViewerScreen --> TraceController
  TraceController --> TraceStoreBoundary
  TraceController --> Conversation
  TraceController --> ChatMessage
  TraceController --> PendingAction
  TraceController --> AICostRecord
```

```mermaid
sequenceDiagram
  actor AD as Admin
  participant S as TraceViewerScreen
  participant C as TraceController
  participant CV as Conversation
  participant MS as ChatMessage
  participant PA as PendingAction
  participant TS as TraceStoreBoundary
  AD->>S: search(userOrGuest, period, flaggedOnly)
  S->>C: listConversations(filter)
  C->>CV: search(filter)
  C-->>S: conversations(cost, toolCount, guardrailFlags)
  AD->>S: open(conversationId)
  S->>C: getTrace(conversationId)
  C->>MS: findByConversation(conversationId)
  C->>PA: findByConversation(conversationId) (confirmed, rejected, expired)
  C->>TS: fetchTrace(traceId) (spans, tool calls, tokens, latency)
  alt trace store unavailable
    C-->>S: messages and actions only
  else
    C-->>S: messages, actions, spans
  end
```
