```mermaid
classDiagram
```

```mermaid
sequenceDiagram
  actor AD as Admin
  participant S as ReportScreen
  participant C as ReportController
  participant O as Order
  participant OI as OrderItem
  participant J as TryOnJob
  participant W as WebcamSession
  participant CV as Conversation
  participant K as AICostRecord
  AD->>S: open(period)
  S->>C: getReport(period)
  C->>O: revenueAndCountByStatus(period) (revenue = DELIVERED orders)
  C->>OI: topProducts(period, limit=10)
  C->>J: usageAndSuccessRate(period)
  C->>W: secondsUsed(period)
  C->>CV: countByRole(period)
  C->>K: costByFeature(period) (chat, try-on, webcam, draft)
  C-->>S: reportData
  opt export
    AD->>S: exportCsv()
    S->>C: exportReport(period, CSV)
    C-->>S: file
  end
```
