### UC11 – Review product

```mermaid
classDiagram
  class ReviewForm { <<boundary>> }
  class AdminProductScreen { <<boundary>> }
  class ReviewController { <<control>> }
  class Review { <<entity>> }
  class Order { <<entity>> }
  class OrderItem { <<entity>> }
  ReviewForm --> ReviewController
  AdminProductScreen --> ReviewController : hideReview
  ReviewController --> Review
  ReviewController --> Order
  ReviewController --> OrderItem
```

```mermaid
sequenceDiagram
  actor CU as Customer
  actor ST as Staff / Admin
  participant F as ReviewForm
  participant AP as AdminProductScreen
  participant C as ReviewController
  participant O as Order
  participant R as Review
  CU->>F: submit(orderItemId, rating 1-5, comment)
  F->>C: createReview(userId, orderItemId, rating, comment)
  C->>O: isCompletedAndOwnedBy(orderItemId, userId)
  C->>R: existsForOrderItem(orderItemId)
  alt not completed, not owner or already reviewed
    C-->>F: error(NOT_ALLOWED)
  else allowed
    C->>R: create(productId, orderItemId, rating, comment)
    C-->>F: saved
  end
  ST->>AP: hide(reviewId)
  AP->>C: hideReview(reviewId)
  C->>R: setHidden(true)
```
