### UC09 – Track order

```mermaid
classDiagram
  class OrderHistoryScreen { <<boundary>> }
  class OrderDetailScreen { <<boundary>> }
  class OrderTrackingController { <<control>> }
  class EmailServiceBoundary { <<boundary>> }
  class Order { <<entity>> }
  class OrderItem { <<entity>> }
  class OrderStatusHistory { <<entity>> }
  class Payment { <<entity>> }
  OrderHistoryScreen --> OrderTrackingController
  OrderDetailScreen --> OrderTrackingController
  OrderTrackingController --> Order
  OrderTrackingController --> OrderItem
  OrderTrackingController --> OrderStatusHistory
  OrderTrackingController --> Payment
  OrderTrackingController --> EmailServiceBoundary
```

```mermaid
sequenceDiagram
  actor A as Customer / Guest
  participant H as OrderHistoryScreen
  participant D as OrderDetailScreen
  participant C as OrderTrackingController
  participant O as Order
  participant SH as OrderStatusHistory
  participant PM as Payment
  participant E as EmailServiceBoundary
  alt Customer
    A->>H: openMyOrders(statusFilter)
    H->>C: listOrders(userId, filter)
    C->>O: findByUser(userId, filter)
    C-->>H: orders (newest first)
    A->>D: open(orderId)
    D->>C: getOrder(orderId, userId)
  else Guest via email link
    A->>D: openLink(guestToken)
    D->>C: getOrderByToken(guestToken)
    alt token invalid or expired
      C-->>D: error(LINK_EXPIRED)
      A->>D: requestNewLink(email)
      D->>C: resendTrackingLink(email)
      C->>E: sendTrackingLinks(email)
    end
  end
  C->>O: load(orderId)
  C->>SH: listByOrder(orderId)
  C->>PM: findByOrder(orderId)
  C-->>D: detail(items, fees, address, statuses, history, trackingCode)
  opt awaiting VietQR payment
    D-->>A: showQrAndCountdown()
  end
```
