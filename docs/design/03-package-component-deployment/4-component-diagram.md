## 4. Sơ đồ component

Vòng tròn là interface; mũi tên từ interface vào component là component cung cấp nó, mũi tên từ component ra interface hoặc dịch vụ ngoài là component cần nó. Tên cạnh mũi tên ra dịch vụ ngoài là interface adapter ở mục 3.3.
